# SatelliteDex 🛰️

Suivi de satellites directement dans le navigateur.

Cette version utilise **CelesTrak** comme alternative ouverte à N2YO : les éléments orbitaux GP/TLE sont récupérés publiquement, puis `satellite.js` calcule la position dans le navigateur. Cela évite d'exposer une clé N2YO.

Inclus : ISS, Tiangong, Hubble, NOAA 20, Landsat 8/9, Terra, Aqua, Suomi NPP et plusieurs Sentinel.

Carte : OpenStreetMap + Leaflet.
Compatible GitHub Pages.
